# daily-task-automator
Test the sync logic: `node tests/sync.test.js`

## Looks

The app comes in 8 UI styles: Skeuomorphism, Neumorphism, Glassmorphism, Claymorphism,
Brutalism, Maximalism, Liquid Glass and Bento Grid. Switch in the 🎨 Look panel, or open
one directly from [`styles/`](styles/). After changing `index.html`, run
`node scripts/build-styles.js` to update the style folders.
